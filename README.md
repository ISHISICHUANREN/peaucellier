# Peaucellier 直线机构 · 交互演示

一个单文件网页：**七根杆，把圆周运动变成严格直线**。可以拖动、可以改参数、杆长实时验证。

打开 `index.html` 即可，无依赖、无构建、不需要联网。

## 玩法

- **拖动画布上的蓝点 P**：它会自动贴着圆走，绿点 P′ 只会沿那条直线移动。
- **三个滑块**：
  - `OB = OD`：长杆长度 `L`
  - `BP = DP`：菱形边长 `S`
  - `曲柄半径 R`：同时决定固定铰 `OA = R`（保证圆过 O）
- **自动旋转**：让曲柄自己转，腾出手看 P′。
- 右下角的表格会实时验证：
  - `OB / OD` 恒等于 `L`
  - `BP / DP / BP′ / DP′` 恒等于 `S`
  - `OP · OP′` 恒等于 `k² = L² − S²`

把 `BP` 调到接近 `OB`，菱形会被压扁——那是机构的**奇异位置**，真实的机构在这里会卡死。

## 强行转满

点「强行转满」，机构不再回避死区，硬转一整圈。你会看到：

- P′ 飞到画面外，被标成 `P′ → ∞`；
- 两根杆够不着彼此，画面用虚线圈标出它们各自的「能够到」范围，并提示还差多少；
- 轨迹在穿过死区的地方**断开**，不会画出一条假连线。

死区的大小是可以算的：需要 `|L−S| ≤ OP ≤ L+S`。曲柄圆过 O，所以 θ=180° 附近总有一段 `OP < L−S`，那段圆弧上**没有解**——不是机构卡住，是几何上画不出来。

默认参数（L=2.6, S=1.9, R=1）下：死区弧长 81.9°，可转 278.1°；边界处 `OP′ = L+S = 4.5`，P′ 在直线上的行程 8.43。

## 焦点曲线

点「焦点曲线」，会画出两条以 O、P 为焦点的曲线：

- **金色椭圆**：`|XO| + |XP| = L + S`
- **紫色双曲线**：`| |XO| − |XP| | = L − S`

**B 和 D 恰好是这两条曲线的交点**——因为它俩同时满足 `OB = L`、`PB = S`。

两条曲线各有一个退化位置，正好对应机构的两个死点：

| 位置 | 退化 |
|---|---|
| `OP → L + S`（远边界） | 椭圆塌成线段 |
| `OP → L − S`（近边界 = 死区） | 双曲线塌成射线 |

也就是说：**机构的死点，就是圆锥曲线的退化**。

## 数学

反演：给定圆心 O、半径 r，点 P 的像 P′ 满足

```
P′ 在射线 OP 上，且  OP · OP′ = r²
```

不过 O 的直线 → 过 O 的圆；过 O 的圆 → 不过 O 的直线。

Peaucellier 机构用六根杆（`OB = OD = L`，`BP = DP = BP′ = DP′ = S`）机械地实现了这个关系：

```
OP · OP′ = L² − S² = k²   （常数）
```

于是当 P 被曲柄 `AP` 约束在过 O 的圆上时，P′ 必然落在直线

```
x = k² / (2R)
```

上，与 R 和 k 有关，与 P 的位置无关。

## 历史

1864 年法国军官 Charles-Nicolas Peaucellier 造出第一个能画出精确直线的连杆机构；1871 年俄国人 Lipkin 独立做出同样的装置，并用于蒸汽机示功器——那里需要一个严格直线的笔尖。

**在精密导轨出现之前，人们用几何代替加工。**

## 部署到 GitHub Pages

1. 在 GitHub 新建仓库，把本目录推上去
2. 仓库 **Settings → Pages → Source: Deploy from a branch → main / (root)**
3. 等一两分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`

## 修改

页面里所有逻辑都在 `index.html` 的 `<script>` 里，状态集中在 `state` 对象：

```js
const state = { L: 2.6, S: 1.9, R: 1.0, theta: -0.6, ... };
```

打开控制台可以直接改：

```js
__state.L = 3.2;      // 改长杆
__state.theta = 1.0;  // 换 P 的位置
```

配色在 `:root` 的 CSS 变量里。
